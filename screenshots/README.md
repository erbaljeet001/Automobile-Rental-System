# Screenshot Instructions

## How to Take Screenshots:

### Windows:

1. Open your browser to `http://localhost/automobile/`
2. Press `Windows + Shift + S` to open Snip & Sketch
3. Select the area you want to capture
4. Save as PNG in the `screenshots/` folder

### Alternative:

- Press `Print Screen` key
- Open Paint/MS Paint
- Paste (Ctrl+V) and save as PNG

## Required Screenshots:

1. **homepage.png** - Main home page showing cars and bikes
2. **signup.png** - Signup form page
3. **login.png** - Login form page
4. **cars.png** - Car listings section
5. **bikes.png** - Bike listings section
6. **booking.png** - Any booking confirmation page
7. **mybookings.png** - My bookings page (after login)

## File Naming:

- Save all screenshots in the `screenshots/` folder
- Use lowercase names with .png extension
- Make sure images are not too large (under 2MB each)

## After Taking Screenshots:

Run these commands:

```bash
git add screenshots/
git commit -m "Add project screenshots"
git push
```
